# Demo artwork

Three original editable example projects: Coin Simulator, Sky Obby and Don't Look.

The backgrounds and transparent characters are rendered from original SVG geometry by
scripts/render-classic-demos.mjs using Sharp. Run node scripts/render-classic-demos.mjs
to regenerate the six image files. They use classic six-part block-avatar proportions,
simple printed faces and game-like obby, simulator and horror environments. They are
illustrations made for Bopzi, not Roblox Studio renders, real game screenshots or user assets.
No third-party game artwork is included.

Each folder contains a 1920 x 1080 background.jpg and a transparent character.png.
Titles, lights and effects are editable Bopzi layers defined in src/lib/demos.ts.
studio.png is a screenshot of the running simplified editor.

The layout gallery has been retired. Existing demo projects remain readable for compatibility.
ai-lava-thumbnail.png is a real output generated through Bopzi's ChatGPT subscription connection
and exported as 1920 x 1080. It is an illustrative game concept, not a real game screenshot.
studio.png now shows that generated image in the current dark Create workspace.

Current ai-lava-thumbnail.png is the newer Roblox GFX reference-guided output,
using Barry's Prison Run for style inspiration and an original noob/lava-obby brief.
It does not depict that reference game's characters or map.
